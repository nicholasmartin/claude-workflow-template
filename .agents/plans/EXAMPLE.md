# Example Plan

This directory holds implementation plans created by `/plan-feature`. Delete this file once you have real plans.

Plans are detailed implementation guides that enable one-pass execution by `/execute`. They contain:

- Feature description and user story
- Codebase file references with line numbers
- Step-by-step tasks in dependency order
- Validation commands for each step
- Acceptance criteria

To create a plan: `/plan-feature add user authentication`

To execute a plan: `/execute .agents/plans/add-user-authentication.md`
